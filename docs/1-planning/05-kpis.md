# KPIs: PortfolioX

Key Performance Indicators used to measure the success of the project.

## Performance
| KPI | Target | How to measure |
|---|---|---|
| Home page load time | Under 2.5 seconds (Largest Contentful Paint) | Lighthouse |
| Lighthouse Performance score | 90 or higher | Lighthouse |
| Portfolio preview update time | Under 300 ms after an edit | Manual testing |
| AI response time (first response) | Under 10 seconds | Manual testing and logs |
| GitHub data fetch time | Under 5 seconds for a typical profile | Manual testing and logs |

## Usability and Accessibility
| KPI | Target | How to measure |
|---|---|---|
| Lighthouse Accessibility score | 95 or higher | Lighthouse |
| Steps to generate a first portfolio | 5 steps or fewer after sign up | User testing |
| Time to build a first portfolio | Under 10 minutes | User testing |
| Task success rate in user testing | 80% or higher | User testing with 5 or more users |
| Keyboard navigation | All pages usable without a mouse | Manual checklist |
| Responsive layout | Works on mobile, tablet, and desktop | Manual testing |

## Quality
| KPI | Target | How to measure |
|---|---|---|
| AI suggestions accepted or lightly edited by users | 70% or higher | User testing feedback |
| Critical bugs at final delivery | 0 | Bug reports |
| Pull requests reviewed before merge | 100% | GitHub |
| Core features completed | Portfolio Builder 100%, GitHub Improver 80% or higher | Task board |

## Reliability and Security
| KPI | Target | How to measure |
|---|---|---|
| Secrets committed to the repository | 0 | Code review |
| Graceful handling of API failures | All errors show a clear message to the user | Manual testing |

## Project Delivery
| KPI | Target | How to measure |
|---|---|---|
| Documents delivered on time | 100% of milestones | Project plan |
| Weekly team meetings held | At least 1 per week | Meeting notes |
| Task completion rate per sprint | 85% or higher | GitHub Issues or task board |
